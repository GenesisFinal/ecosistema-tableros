# Ecosistema de Tableros | La Segunda Seguros

Portal unificado y contenedor interactivo para el acceso al ecosistema de herramientas analíticas, financieras, actuariales y de mercado asegurador.

Diseñado y estructurado bajo los lineamientos oficiales de identidad visual del **Brandbook de La Segunda Seguros** (Tipografía *Sora*, paleta de *Rojos Institucionales* `#e20039` / análogos, acentos complementarios, retícula en mosaico y estándares de marca).

## 🎨 Identidad Visual & Brandbook

- **Tipografía Institucional:** `Sora` (pesos 300, 400, 500, 600, 700, 800) importada vía Google Fonts.
- **Color Principal ("Rojo Seguro"):** `#e20039` (Pantone 192 C/U).
- **Paleta de Rojos Análogos:** `#b91f38` (Pantone 193 C/U), `#f42c4b` (Pantone 191 C/U), `#ff4c60` (Pantone 190 C/U).
- **Colores Complementarios:** Amarillo Oro `#f8cc59`, Coral `#ff593e`, Vino `#512420`, Charcoal `#30302d`, Menta `#3ac792`, Azul `#4183ca`.
- **Mosaico Institucional:** Franja y patrones geométricos distintivos de La Segunda.
- **Claims Oficiales:** *"Primero lo que importa. Lo primero sos vos."*

## 🌐 Publicación en GitHub Pages

1. Sube este repositorio a tu cuenta de GitHub (por ejemplo, en el repo `ecosistema-tableros` o similar).
2. Ve a **Settings** > **Pages** en tu repositorio.
3. En la sección **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
4. Haz clic en **Save**. En unos minutos tu sitio estará en línea en:
   ```
   https://<tu-usuario>.github.io/<nombre-del-repo>/
   ```

## 💡 Funcionalidades del Portal

- **Buscador predictivo en tiempo real:** Búsqueda por título, descripción o palabras clave/tags.
- **Filtros rápidos por categoría:** Segmentación instantánea de herramientas.
- **Modal interactivo:** Detalle de capacidades y fuentes de cada tablero con botón de lanzamiento directo.
- **Diseño Responsive:** Adaptado para teléfonos móviles, tablets, laptops y monitores ultrawide.
- **Zero build dependencies:** HTML5, CSS3 y JavaScript nativo, ligero y de carga ultrarrápida.
